# How to run:

## to run/setup properly
```
git clone https://github.com/h-kakar11/yt-steal.git
```
or, just download the `.exe`.

then, run  `Ytsteal-Setup.exe` (you only need to run this once).
this `.exe` file downloads:
[ffmpeg](https://github.com/ffmpeg/ffmpeg)
[ytdlp](https://github.com/yt-dlp/yt-dlp) )
[deno](https://docs.deno.com/)
these are all required for the extension to work. 

once you have run the `.exe`, it give instructions:
```
Done. Ytsteal 2.0.0 is installed.

One last step, once per browser (Chrome, Edge, Brave or Chromium):
  1. Open the extensions page: chrome://extensions  (edge://extensions, brave://extensions)
  2. Turn on "Developer mode" (top right).
  3. Click "Load unpacked" and choose this folder:
       C:\Users\YourUsername\AppData\Local\Ytsteal\extension
  4. Pin Ytsteal to the toolbar. Press Alt+Shift+D on any YouTube video to download it.

Press Enter to close this window.
```
Just follow them if you want. the 3rd one gives the directory to the actual extension file.
