Ytsteal settings

Changes save automatically.

Where files go

Video

MP4 plays on almost every device. Higher qualities take longer and use more space.

Audio only

MP3 works everywhere. FLAC and WAV are lossless but much bigger.

Extras

Speed and sign-in

This reads the sign-in cookies from the browser you choose. Keep it off unless you need it. It may fail with the newest Chrome versions.

Keyboard shortcuts

    Press a shortcut on any YouTube video to download it. You can change the keys on the shortcuts page.

    Engine

    Ytsteal uses yt-dlp to fetch videos. It updates itself once a week. YouTube changes often, so if downloads start failing, update it.

    Reset

    Put every setting back to what it was when you installed Ytsteal. Your files are not touched.
